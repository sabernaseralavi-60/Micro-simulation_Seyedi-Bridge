# S3 — میدان مدرن/توربو (Modern/Turbo Roundabout)

**وضعیت: `planned`** — طراحی مفهومی ثبت شده؛ ساخت شبکه هنوز انجام نشده.

## محدودیت فیزیکی حاکم

امکان‌سنجی این سناریو مستقیماً به سازهٔ ۷دهانه‌ای پل گره خورده است (رجوع به
`config/assumptions.yml -> bridge_geometry.span_structure` و
[[seyedi-pier-structure]]): گردش پیوستهٔ میدان حول یک جزیرهٔ مرکزی نیازمند
مسیر باز پیوسته است، اما دهانهٔ مرکزی زیر پل در وضع موجود **بسته** است و
فقط یک دهانه در هر سمت (غرب/شرق) باز است.

## دو گزینهٔ طراحی

1. **میدان کامل مشروط:** باز کردن دهانهٔ مرکزی به‌عنوان مسیر سوم گردش —
   مشروط به تأیید ظرفیت باربری سازه توسط مهندس سازه (خارج از حیطهٔ این
   مطالعهٔ ترافیکی؛ فرض کالیبراسیون‌نشده و صریحاً به‌عنوان «مشروط» در گزارش
   علامت‌گذاری می‌شود).
2. **میدان نامتقارن محدود:** طراحی میدان کوچک/بیضی فقط با استفاده از دو
   دهانهٔ باز موجود (بدون دهانهٔ مرکزی) — انحراف (deflection) کمتر، ظرفیت
   کمتر، اما بدون نیاز به تأیید سازه‌ای.

## پیش‌نیاز ساخت

- تصمیم‌گیری دربارهٔ گزینهٔ ۱ در ۲ نیازمند ورودی صریح کاربر/تیم پروژه (این
  یک Checkpoint واقعی است، نه صرفاً یک انتخاب مهندسی داخلی) پیش از پیاده‌سازی.
- در صورت گزینهٔ ۲: طراحی هندسی جزایر قطره‌ای و انحراف با اسکریپت پایتون روی
  plain-XML (مشابه رویکرد S1 اما با گره‌های جدید، نه فقط بازتایپ).
