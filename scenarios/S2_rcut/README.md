# S2 — محدودسازی گردش‌ها + دوربرگردان (RCUT / Median U-Turn)

**وضعیت: `planned`** — طراحی مفهومی ثبت شده؛ ساخت شبکه هنوز انجام نشده
(رجوع به `config/scenarios.yml -> S2_rcut`).

## منطق طراحی

معادل بین‌المللی: **RCUT (Restricted Crossing U-Turn)** یا **Median U-Turn
(Michigan Left)**. گردش چپ مستقیم زیر پل حذف می‌شود؛ به‌جای آن، خودرو مستقیم/
راست ادامه می‌دهد و در یک دوربرگردان (U-turn) در فاصلهٔ معین از تقاطع مسیرش
را کامل می‌کند.

**قید صریح کاربر:** دوربرگردان‌ها باید **دور از مرکز پل** باشند، چون سرعت
روی عرشه بالاست.

## محاسبهٔ فاصلهٔ دوربرگردان (برای توجیه در گزارش)

فاصلهٔ لازم = طول تشخیص+واکنش + طول کاهش سرعت + طول بافت (weaving):

- طول تشخیص+واکنش: `d_PR = v × t_PR` (t_PR ≈ ۲.۵ ثانیه، AASHTO)
- طول کاهش سرعت: `d_dec = v² / (2×a_dec)`
- طول بافت: بر اساس تعداد خط تغییر مسیر لازم × نرخ بافت متعارف (~۳۰-۶۰ متر/خط)

با سرعت طرح عرشه (فرضاً ۶۰-۸۰ km/h، رجوع به assumptions.yml برای دقیق‌سازی)،
سه سطح فاصله به‌عنوان متغیر حساسیت آزموده می‌شود: **۱۵۰ / ۲۵۰ / ۳۵۰ متر**.

## پیش‌نیاز ساخت

- تعیین محل دقیق دو دوربرگردان (شرق و غرب پل) روی عرشه، خارج از bbox فعلی
  اگر فاصلهٔ ۳۵۰ متر از آن فراتر رود (نیاز به بررسی مجدد `bbox_half_extent`).
- پچ plain-XML: بستن اتصال‌های گردش چپ زیر پل + افزودن گره/یال دوربرگردان
  روی عرشه (احتمالاً نیازمند گرهٔ جدید، نه فقط بازتایپ گرهٔ موجود — برخلاف
  S1 که فقط بازتایپ بود).
